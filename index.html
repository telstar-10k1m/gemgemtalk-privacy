젬젬톡 개인정보처리방침

시행일 2026년 10월 21일 · 10kM.ai · 사내용 앱

젬젬톡(GemGemTalk, 패키지 이름 com.gemgem.talk)은 10kM.ai 가 임직원이 쓰도록 만든 안드로이드 앱입니다. 주소록에서 고른 사람에게 이름이 자막으로 들어간 영상 문자(MMS)를 보냅니다. 이 문서는 앱이 어떤 정보를 어디까지 다루는지 설명합니다.

1. 앱이 다루는 정보

정보어디서어떻게 쓰나어디에 두나
받는 사람 이름·전화번호사용자가 주소록에서 고르거나 직접 입력영상 자막에 이름을 넣고, 그 번호로 문자를 보냄사용자 폰 안에만 저장. 서버로 보내지 않음
문자 본문·영상사용자가 입력·선택문자로 보냄폰 안. 「새로 만들기」를 쓸 때만 광고 문구가 서버로 감(이름 자리는 비워서)
발송 기록앱이 생성누구에게 보냈는지 결과 확인(번호는 뒷자리만 표시)폰 안. 사용자가 CSV 로 내보낼 수 있음

2. 앱이 쓰는 권한

  • 연락처 읽기 — 받는 사람을 주소록에서 고르기 위해. 고른 사람만 명단에 들어가며, 주소록 전체를 저장하거나 보내지 않습니다.
  • SMS 보내기 — 만든 영상을 사용자 본인 회선으로 영상 문자(MMS)로 보내기 위해. 사용자가 「시작」을 누를 때만 보내고, 문자를 읽지 않습니다.
  • 인터넷 — 「새로 만들기」로 영상을 만들 때 10kM.ai 영상 서버와 통신하기 위해.
  • 알림·포그라운드 서비스 — 보내는 동안 진행 상황을 알림으로 보여 주고, 앱을 닫아도 발송을 이어가기 위해.

3. 밖으로 나가는 정보

앱이 외부로 보내는 것은 다음뿐입니다.

  • 10kM.ai 영상 서버로: 「새로 만들기」에 쓴 광고 문구와 만들기 옵션(엔진·비율·길이·목소리). 받는 사람 이름·번호·명단은 보내지 않습니다.
  • 이동통신사로: 사용자가 보내기로 한 영상 문자(받는 번호·본문·영상). 일반 문자 발송과 같습니다.

광고·분석 SDK 는 넣지 않았습니다. 사용 기록을 수집하지 않습니다.

4. 보관과 삭제

  • 명단·문자·발송 기록은 폰 안에만 있고, 앱의 「새 캠페인」·「지우기」로 지우거나 앱을 삭제하면 함께 지워집니다.
  • 서버에 만든 영상과 광고 문구는 사용자가 앱에서 지우거나 서버 관리자가 정리할 때까지 서버에 남습니다(영상 안에 개인정보는 들어 있지 않습니다).

5. 이용 대상

이 앱은 10kM.ai 임직원 전용이며 스토어에 공개 배포하지 않습니다. 만 14세 미만을 대상으로 하지 않습니다.
